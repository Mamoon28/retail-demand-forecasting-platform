# CV Bullets — use only after you have run and understood the project

## Data Scientist version
**Retail Demand Forecasting Platform | Python, TensorFlow/Keras, SQL, BigQuery, dbt, FastAPI, Docker**
- Built an end-to-end retail demand forecasting workflow on Google BigQuery e-commerce data, comparing weekly seasonal-naive, ARIMA and TensorFlow/Keras LSTM models using time-based validation and MAE/RMSE/MAPE.
- Engineered daily demand datasets using dbt and SQL, then productionised model inference through a FastAPI service and Docker container.
- Added automated unit testing and GitHub Actions CI, with an Airflow DAG for repeatable transformation, training and validation workflows.

## Data Engineer version
**Retail Demand Data Platform | SQL, Python, BigQuery, dbt, Airflow, GitHub Actions**
- Built an end-to-end ELT workflow on Google BigQuery public e-commerce data, transforming raw operational tables into reusable staging, fact, dimension and demand-mart models using dbt.
- Implemented dbt data-quality tests for uniqueness, nulls and referential integrity, with reusable SQL transformations and documented business logic.
- Added Airflow orchestration and GitHub Actions CI to automate transformation, model-training and validation workflows and improve reproducibility.
